Refreshed September 25, 2026 for a 60-minute beginner webinar.

The deck retains its original plain, unbranded template. The three original sections and all six starter workbooks remain. The lesson uses native Excel formulas, charts and PivotTables. It does not include a Python-assisted analysis demonstration.

## Scope and current guidance

The forecast is a short FORECAST.LINEAR illustration on the historical monthly totals. It does not model seasonality. The newer-capabilities tour uses one optional live example and brief explanations of the remaining features.

Microsoft references are included in the slide notes, presenter notes and handouts. Interface labels and access depend on the subscription, version and organization settings. The old cloud/AutoSave-only setup rule and App Skills licensing shortcut have been removed. The =COPILOT preview function is not part of the lesson.

The external EITI visualization style guide is a legacy reference, not part of the refreshed participant materials. It is excluded from the refreshed package.
